# Звіт до лабораторної роботи №07.2: Тестування з бібліотекою pytest

## 1. Мета роботи
Ознайомитися зі сторонньою бібліотекою `pytest` для написання лаконічних модульних тестів на Python: перевіркою умов через стандартний оператор `assert`, тестуванням винятків (`pytest.raises`), параметризацією тестових даних (`@pytest.mark.parametrize`), використанням фікстур (`@pytest.fixture`) із різними областями видимості (`scope`) та групуванням тестів за допомогою кастомних маркерів (`@pytest.mark.unit`).

---

## 2. Налаштування середовища та команди запуску
Для роботи використовувалося віртуальне середовище `.venv` та бібліотека [pytest](https://docs.pytest.org/).

### Основні команди, використані під час виконання роботи:
```bash
# Активація віртуального середовища та встановлення pytest
source .venv/bin/activate
/Users/admin/Desktop/testing/.venv/bin/python -m pip install pytest

# Запуск усіх тестів із детальним виводом
pytest -v

# Запуск лише тестів, позначених маркером unit
pytest -m unit -v

# Перегляд списку зібраних тестів без їх запуску
pytest --collect-only

# Зупинка після першої помилки зі скороченим traceback (перевірка поломки тесту)
pytest -x --tb=short
```
